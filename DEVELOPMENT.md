# ACEest Fitness & Gym - Development Guide

## Project Overview
A professional Flask web application for fitness gym management with comprehensive testing and deployment pipelines.

## Technology Stack
- **Backend**: Flask 3.1.0
- **Runtime**: Python 3.12
- **Testing**: pytest 8.3.4
- **Code Quality**: flake8 7.1.1
- **Server**: Gunicorn 23.0.0
- **Containerization**: Docker
- **CI/CD**: GitHub Actions, Jenkins

## Project Setup
1. Clone repository
2. Create virtual environment
3. Install dependencies from requirements.txt
4. Run Flask app on port 8080

## Initial Features Implemented
- Health check endpoint (/health)
- Programme catalogue with 4 fitness programmes
- RESTful API with 7 endpoints
- Request validation and error handling
